# Legitsoft_Assignment

**Task 1 – HTML Profile Page**
This task focuses on creating a personal profile webpage using semantic HTML. It includes a navigation bar, a hero section with basic details, and structured sections like About, Skills, Education, Projects, Languages, and Contact, ensuring clear layout and readability.

**Task 2 – CSS Styling**
This task focuses on enhancing the HTML profile page using advanced CSS. It includes the use of CSS variables, custom fonts, and a dark-themed design system. The styling improves layout, typography, and visual hierarchy while adding modern UI elements like cards, hover effects, smooth animations, and responsive design for different screen sizes.

**Task 3 – Bootstrap Landing Page**
This task involves building a modern and responsive landing page using Bootstrap. It includes sections like navbar, hero, features, how-it-works, testimonials, pricing, CTA, and footer. The design uses Bootstrap’s grid system, components, and custom styling to create a professional UI with animations, cards, and responsive layouts.

**Task 4 – Tailwind Pricing Page**
This task involves building a responsive pricing page using Tailwind CSS. It includes multiple pricing plans (Free, Basic, Pro, Enterprise) with a clean card-based layout, along with features like monthly/yearly price toggle, dark mode switch, and hover animations for better user interaction.

**Task 5 – React To-Do App**
This task involves building an interactive to-do application using React. It includes features like adding, editing, deleting, and marking tasks as completed, along with filtering (all, active, completed). The app also uses localStorage for data persistence and provides a clean, responsive UI with real-time updates.

**Task 6 – React + Tailwind Dashboard**
This task involves building a responsive dashboard using React and Tailwind CSS. It includes a sidebar for navigation, a header with search functionality, stat cards displaying key metrics, and a dynamic table for managing data. The dashboard demonstrates component-based design, state management, and real-time filtering with a clean and modern UI.
